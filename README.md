# Customer Data Cleaning with Python and Pandas

## Project Overview
This project demonstrates basic data-cleaning techniques using Python and Pandas on a sample customer dataset.

## Objectives
- Standardize customer names and city names.
- Identify invalid ages and replace them with missing values.
- Detect and remove duplicate records.
- Inspect missing values and dataset dimensions.
- Export the cleaned dataset to CSV.

## Tools Used
- Python
- Pandas
- Git and GitHub

## Files
- `customer_cleaning.py` — Python script containing the data-cleaning operations.
- `cleaned_customers.csv` — exported cleaned dataset.

## Results
The sample dataset was reduced to four unique customer records. Invalid age data was marked as missing rather than guessed, and missing values were identified for further review.

## How to Run
1. Install Python and Pandas.
2. Open a terminal in the project directory.
3. Run:

   `python customer_cleaning.py`

## Data Notice
The dataset contains sample customer records created for learning purposes.
